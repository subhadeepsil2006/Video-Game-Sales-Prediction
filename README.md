# 🎮 Video Game Sales Prediction

### A Machine Learning-Based Approach to Predicting Video Game Sales

---

## 📌 Project Overview

The **Video Game Sales Prediction** project is a Machine Learning-based project that focuses on analyzing video game sales data and predicting sales performance using various game-related attributes.

The project explores the relationship between different factors such as game platforms, genres, publishers, and regional sales. By applying data preprocessing, exploratory data analysis (EDA), and machine learning techniques, the system aims to identify meaningful patterns in historical video game sales data and develop a predictive model to estimate sales performance.

## 🎯 Project Objectives

- Analyze video game sales data to understand sales patterns.
- Perform data cleaning and preprocessing.
- Identify important factors influencing video game sales.
- Conduct Exploratory Data Analysis (EDA).
- Analyze regional and global video game sales trends.
- Apply Machine Learning algorithms for sales prediction.
- Evaluate model performance using appropriate evaluation metrics.
- Understand the relationship between game attributes and sales performance.

## 📊 Dataset Information

The project uses a video game sales dataset containing information about different video games and their sales performance.

The dataset is used for:

- Data exploration and statistical analysis.
- Identifying missing and duplicate values.
- Data preprocessing and feature selection.
- Analyzing video game sales trends.
- Understanding relationships between different game attributes and sales.
- Training and evaluating the prediction model.

## 🛠️ Technologies & Tools Used

- **Python:** Main programming language used for project development.
- **Google Colab:** Cloud-based environment for writing and executing code.
- **Pandas:** Used for data manipulation and analysis.
- **NumPy:** Used for numerical computations.
- **Matplotlib:** Used for data visualization.
- **Seaborn:** Used for statistical data visualization.
- **Scikit-learn:** Used for implementing Machine Learning algorithms and model evaluation.

## ⚙️ Project Workflow

1. **Data Collection:** Load the video game sales dataset.
2. **Data Preprocessing:** Handle missing values, duplicate records, and prepare the data.
3. **Exploratory Data Analysis:** Analyze sales distributions, trends, and relationships.
4. **Feature Selection:** Identify relevant attributes for sales prediction.
5. **Model Development:** Apply suitable Machine Learning algorithms.
6. **Model Evaluation:** Evaluate predictive performance using appropriate metrics.
7. **Prediction:** Estimate video game sales based on selected features.

## 🚀 How to Run the Project

**Step 1: Clone the Repository**

```bash
git clone https://github.com/YOUR_USERNAME/Video-Game-Sales-Prediction.git
```

**Step 2: Navigate to the Project Directory**

```bash
cd Video-Game-Sales-Prediction
```

**Step 3: Install Required Libraries**

```bash
pip install pandas numpy matplotlib seaborn scikit-learn
```

**Step 4: Open the Notebook**

Open `Video_Game_Sales_Prediction.ipynb` using Google Colab or Jupyter Notebook.

**Step 5: Load the Dataset**

Load the video game sales CSV dataset into the notebook.

**Step 6: Execute the Project**

Run all notebook cells sequentially to perform data preprocessing, exploratory data analysis, model training, evaluation, and sales prediction.
